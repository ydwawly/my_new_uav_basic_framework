## 基线

整理前基线可完成 ARM Debug 构建，但质量门禁中 4/11 项测试因测试契约落后于现行实现而失败：MTF02 仍按旧 ISR 解析方式断言、VQF 测试依赖仓库外上位机、控制测试检查旧状态机、SPI 主机桩缺少 CMSIS 内建函数。测试已改为验证当前正式行为，没有借此修改控制算法。

## 硬件无桨回归

本轮仓库整理未自动烧录硬件。以下项目在发布或合并前仍需由操作者在拆桨条件下完成：

- 启动与全部传感器初始化。
- IMU→姿态→控制事件链和数据新鲜度。
- 物理遥控器、Failsafe、解锁与上锁。
- 四路电机顺序、方向、锁定脉宽和急停。
- SD 挂载、持续日志、日志下载和掉卡恢复。
- USB/MAVLink 双向满载。
- SystemView 连接、任务/ISR 识别和 90 s 压力记录。
