# 性能报告与复现方法

## 阅读说明

本报告包含三类数据，必须分开理解：

1. **数据集 A**：Q15 FFT 改造后的飞行热路径测试，重点测量完整控制延迟、姿态计算、FFT 和 SensorHub。
2. **数据集 B**：Q15 FFT 改造前、物理遥控器在线时的系统级满载测试，重点测量任务、ISR、栈、Heap、Cache 对照和通信/SD 压力。
3. **当前公开构建**：移除私有性能探针后的链接器静态资源结果。

数据集 A 和 B 的固件、负载和测试窗口不同，不得把两组最优值拼接为同一次测试结果。历史数据来自目标端 DWT 周期计数器、FreeRTOS 状态及主机压力脚本，不是导出的 SystemView 原始记录。当前公开代码保留 SystemView，但尚未完成同口径硬件复测。

所有测试均为无桨台架测试；涉及“解锁”的场景已断开电机动力电源。

## 数据集 A：Q15 FFT 改造后

### 固件与方法

- 测试日期：2026-09-25。
- 性能测试 ELF SHA-256：`87538599979597E77C33CAF6E8D43F510EFD56CB27DD640D3299E2849201CA3E`。
- BIN SHA-256：`CA2731C4A5ED6694DA9514BBB7FFF7D6452A6B1F86AB0038740D644C11818367`。
- SystemView 自动启动关闭；使用目标端 DWT/FreeRTOS 计时探针读取统计快照。
- BMI088 为物理数据源，采样率约 1 kHz。

FFT 从 `Attitude` 移至现有 `sensor_hub` 任务，不增加任务。姿态任务把每个 24 B 三轴样本写入 2 KiB DTCM 单生产者/单消费者环形缓冲区；SensorHub 每轮最多消费 16 个样本，并且每轮最多计算一个轴的 512 点 `arm_rfft_q15`。X/Y/Z 分三个调度周期完成，以限制单次执行时间。

### 完整控制链路

端点“控制业务完成”位于本次控制迭代完成姿态外环、角速度环、Mixer 与输出更新之后，比只统计控制任务开始更能代表飞行热路径延迟。

| 场景 | 样本 | DRDY→Control start min/avg/max | DRDY→Control complete min/avg/max | Control work min/avg/max |
|---|---:|---:|---:|---:|
| 上锁对照 | 67,023 | 100 / 109.883 / 216 µs | 102 / 111.880 / 218 µs | 5.453 / 6.335 / 18.035 µs |
| 解锁常规负载 | 54,010 | 101 / 110.843 / 218 µs | **103 / 121.690 / 234 µs** | 5.695 / 15.237 / 39.535 µs |
| 解锁组合满载有效窗口 | 42,020 | 101 / 115.486 / 236 µs | **102 / 129.900 / 253 µs** | 5.760 / 18.985 / 49.528 µs |

解锁常规负载使用 25 Hz MAVLink RC，CH8 解锁、油门 1120，电机动力断开；`arm_request=1`、速率环有效、无电机故障。CPU Load 20.7%，上下文切换约 6,996 次/s；Control release→finish 为 10 / 23 / 52 µs，1 ms deadline 超期 0 次，最差余量 948 µs。

组合满载同时包含：

- 25 Hz MAVLink RC。
- 约 1 kHz PING。
- 约 500 Hz TIMESYNC。
- 约 500 Hz HIL_SENSOR 解包；HIL 未启用，仅施加解析负载。
- 下载 248,715,578 B 的已有日志文件。

该有效窗口 CPU Load 为 51.5%，上下文切换约 16,589 次/s；Control release→finish 为 10 / 27 / 67 µs，deadline 超期 0 次，最差余量 933 µs。

> 限制：计划中的 90 s 组合压力在约 35 s 后出现 USB TX 队列饱和，主机脚本不再持续发送 RX 流量。因此上表只报告饱和前的有效双向窗口，不能据此宣称 90 s 满载长稳通过。

### 姿态、FFT 与 SensorHub

| 指标 | 样本/窗口 | min | avg | max |
|---|---:|---:|---:|---:|
| Attitude 完整计算 | 33,006 | 19.160 µs | 57.842 µs | 160.440 µs |
| 单轴 512 点 Q15 FFT | 762 | 104.955 µs | 122.980 µs | 274.163 µs |
| SensorHub release→start | 41.062 s | 1 µs | 11 µs | 201 µs |
| SensorHub work | 41.062 s | 2 µs | 17 µs | 288 µs |
| SensorHub release→finish | 41.062 s | 6 µs | 29 µs | 320 µs |

Attitude 统计包含滤波、VQF、ESKF 预测、当次可用的外部观测更新和结果发布，并非只统计 VQF。SensorHub deadline 为 5,000 µs，超期 0 次，最差余量 4,680 µs。

FFT 单轴耗时分布：762 次中，672 次不超过 128 µs，84 次位于 128–256 µs，6 次超过 256 µs。按每 128 ms 计算三轴 FFT，平均 CPU 占用估算为：

```text
3 × 122.980 µs / 128 ms ≈ 0.288%
```

33.073 s 管线确认窗口内：推送 33,073 个样本、消费 33,072 个、积压 1 个（24 B）、丢弃 0 个；执行 765 次单轴 FFT，完成并发布 255 组三轴结果。41.062 s 环回窗口累计完成超过 481 次 2 KiB 缓冲区回绕，最终积压 3 个样本（72 B）、丢弃 0 个。

### 通信与 SD 压力

目标端 68.551 s 快照：接收 2,290,156 B / 64,459 条 MAVLink 消息，丢弃字节 0，序号丢失 0；DataRouter 投递/分发 75,189 / 75,189，槽池耗尽 0，队列投递失败 0，USB 入队丢弃 0，路由队列峰值 5 / 8。

主机 90 s 统计：接收 5,858,062 B，发送 3,134,061 B，接收包 103,949，飞控序号丢失 0；主机侧待发送队列丢弃 3,062 次。SD 历史日志下载约 505 条 LOG_DATA/s，SD 任务 CPU 峰值 17.4%，未记录 FatFs/write/sync 错误。

## 当前版本复测方法

当前版本应使用 `RelWithDebInfo` 和 SystemView 复测，不重新加入常驻私有性能任务：

1. 记录 Git 提交 SHA、编译器版本、CMake 选项和最终 ELF SHA-256。
2. 拆桨并断开电机动力，记录供电、传感器、SD、物理遥控、USB 主机及解锁状态。
3. 采集不少于 30 s 的空闲/物理遥控基线。
4. 采集不少于 90 s 的解锁组合压力：物理遥控在线、正常日志写入、USB/MAVLink 双向流量和日志下载。
5. 导出每个任务的执行时间、周期、抖动、阻塞、CPU、栈水位和 deadline；报告 min/avg/p95/p99/max。
6. 导出每个 ISR 的进入时间、执行时间、嵌套和被屏蔽区间；区分“响应延迟”和“Handler 执行时间”。
7. 用用户事件标记 DRDY、Attitude 完成、Control 开始及 PWM 更新，统计完整 DRDY→输出链路。
8. 记录 Heap、队列/环形缓冲/槽池峰值、丢弃计数、SD 错误和 MAVLink 序号丢失。
9. 保存统计导出和复现命令，不提交包含本机路径、探针序列号的原始配置。
