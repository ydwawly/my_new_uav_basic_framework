## 运行时测试方法

使用 `RelWithDebInfo` 和 SystemView，不在飞行热路径重新加入私有计时探针：

1. 构建并烧录同一 Git 提交，记录提交 SHA、编译器版本和 CMake 选项。
2. 拆桨；记录供电、传感器、SD 卡、遥控器、USB 主机和是否解锁。
3. 先采集 30 s 空闲基线，再采集至少 90 s 压力窗口：物理遥控在线、解锁、SD 日志开启、USB/MAVLink 持续收发。
4. 对每个任务统计激活次数、最小/平均/最大执行时间、周期、抖动、阻塞时间和 CPU 占比。
5. 对每个 ISR 统计响应延迟、执行时间和嵌套；重点检查 BMI088 DRDY/SPI DMA、SDMMC、USB、UART 和 SPL06 EXTI。
6. 测量端到端链路：BMI088 DRDY → Attitude 开始/结束 → Control 开始/电机输出完成。
7. 记录 FreeRTOS 栈高水位、Heap 当前/最小剩余量、队列/槽池高水位、丢弃计数、SD 写入失败和通信错误。

## 必须报告的运行时指标

| 类别 | 指标 |
|---|---|
| 实时链路 | IMU→Attitude、Attitude→Control、IMU→电机输出的 min/avg/p95/p99/max |
| 任务 | 执行时间、周期、抖动、激活次数、CPU 占比、最长阻塞 |
| 中断 | 响应延迟、ISR 时长、嵌套和最长关中断区间 |
| 资源 | 各任务栈余量、Heap 最小剩余量、消息/路由/SD 槽池高水位 |
| I/O | SD 吞吐与最长事务、USB/MAVLink 吞吐、丢帧/重试/错误计数 |
| 算法 | VQF、ESKF 预测、光流/测距更新、分轴 Q15 FFT 的执行时间分布 |

Cortex-M7 没有通用硬件 D-Cache 命中率性能计数器，SystemView 也不能直接给出可靠命中率。可用 ETM/专用追踪设备或对照实验评估 Cache 影响，但不得把推算值标成实测命中率。

## 当前运行时结果状态

清理后的候选固件尚未执行完整无桨压力复测，因此本报告不沿用旧固件的微秒级结果。硬件复测完成后，应在本节填写固件提交 SHA、完整条件和导出的统计表，再将验证状态更新为通过。
