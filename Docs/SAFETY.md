# 安全边界

本项目用于学习、验证和作品展示，不是适航、量产或功能安全认证固件。任何硬件测试和实飞由操作者自行评估风险。

## 强制无桨场景

- 首次烧录或更换固件。
- 修改电机映射、Mixer、PWM、解锁条件或遥控通道。
- 修改 IMU 安装方向、坐标系、滤波器、VQF/ESKF 或控制参数。
- 使用调试器暂停、单步、断点或 SystemView 高负载采集。
- 验证失联保护、传感器断开、SD/USB 满载和异常恢复。

当前 `APP_ENABLE_MOTOR_OUTPUT` 为 `1U`，系统会初始化 PWM；未解锁时输出锁定脉宽不等于可以带桨调试。

## 上电检查

1. 拆桨并固定机架，确认供电限流。
2. 核对四路电机编号、旋向和 TIM1 引脚。
3. 检查 `app_system_status`：IMU、通信、命令、姿态、控制和电机初始化均符合预期。
4. 静置约 2 s 完成姿态对准，手动倾斜机体核对 Roll/Pitch/Yaw 方向。
5. 检查 SBUS 原始值、Failsafe、解锁通道和低油门条件。
6. 逐路低占空比验证电机，不跨过人员和易损物。
7. 验证断开遥控、姿态超时和输出失败都会进入锁定/急停路径。

## 已实现的安全机制

- 遥控 Failsafe 与命令时间戳超时。
- 姿态反馈接收时间和样本时间双重检查。
- 四元数、步长、陀螺和导航状态的有限性/范围检查。
- 低油门解锁条件、显式上锁和电机故障锁存。
- 控制任务超时只执行安全检查，不用旧姿态重复更新 PID。
- 导航失效只退出定高；姿态/角速度控制是否继续由基础飞行条件决定。

## 尚未声明的保证

- 未完成全包线实飞、温度、振动、电磁兼容、掉电和长时间耐久认证。
- 未实现双 MCU、独立硬件看门狗安全链或形式化验证。
- 传感器冗余当前主要用于对照/诊断，不代表具备认证级故障隔离。
- 参数只适用于当前机架、动力和传感器安装，禁止直接迁移到其他飞机。
